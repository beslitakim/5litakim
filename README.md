# VALO TAKIM — MVP Prototipi

Bu klasör, VALORANT oyuncu eşleştirme uygulamasının ilk çalışan arayüz prototipidir.

## İçerik
- Ana menü
- 1 Kişi Lazım ilanları
- 5'li Takım Bul akışı
- Kayıt formu
- Giriş formu
- İlan oluşturma formu
- Örnek takım odası
- Oda içi sohbet arayüzü
- Rank / rol / oyun modu filtreleri

## Çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterlidir.

## Sonraki geliştirme
1. PostgreSQL veritabanı
2. Gerçek üyelik ve güvenli oturum
3. Kullanıcı profilleri
4. Gerçek 5'li eşleştirme algoritması
5. Gerçek zamanlı oda sohbeti
6. Oda/ilan durumları
7. Şikayet ve moderasyon
8. Riot/VALORANT servisleriyle uyum ve ID doğrulama seçeneklerinin incelenmesi

Not: Bu prototip Riot Games ile bağlantılı değildir ve resmi VALORANT servisi değildir.
